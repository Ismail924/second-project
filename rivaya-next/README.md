# RIVAYA 4

Текущий проект RIVAYA 4.0.1-rc2. Основа — существующая 4.0.0-rc1, пакет `app.rivaya.smart01` и ключ локального хранилища сохранены.

Экраны «Сегодня» и «Профиль» — визуальный эталон. «План» и «Прогресс» используют тот же неоновый стиль.

Реальные шаги читаются из Health Connect: суммарная активность за местные календарные сутки и последние семь дней. На устройстве должен быть источник шагов, записывающий данные в Health Connect. Ручного ввода и тестовых шагов нет.

Персональные уведомления сохраняются нативно и восстанавливаются после перезагрузки, обновления приложения и изменения времени. Без разрешения точных будильников Android может доставлять их с задержкой.

Резервные копии сохраняются через системный выбор файла. Перед восстановлением проверяется структура и сохраняется локальная точка восстановления. Разрешение Health Connect не переносится из копии.

Проверка: `gradle :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug`, затем `gradle :app:connectedDebugAndroidTest` на Android Emulator API 35. APK для обновления необходимо подписать исходным ключом RIVAYA; debug APK не заменяет подписанный релиз.
