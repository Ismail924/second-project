# RIVAYA 3.0 CLEAN

Новая чистая Android-основа RIVAYA, собранная без ручной правки APK.

Перед выдачей APK workflow выполняет:
- Gradle-сборку Android 35;
- запуск на Android Emulator API 35;
- загрузку интерфейса;
- вызов системного выбора фото профиля;
- возврат из системного выбора обратно в приложение.

Тестовая версия использует отдельный пакет `app.rivaya.next`, поэтому ставится рядом со старой RIVAYA.
